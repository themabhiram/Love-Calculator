# Love Calculator

A simple beginner-friendly Python program that calculates a love compatibility score based on the names entered by two people.

## About The Project

The Love Calculator takes two names and checks how many times the letters from **TRUE LOVE** appear in those names.

It then combines the results to generate a love compatibility score.

> This is a fun programming project and is not a real measure of relationship compatibility.

## Features

- Takes two names as input
- Counts letters from `TRUE`
- Counts letters from `LOVE`
- Generates a compatibility score
- Displays different messages based on the score
- Simple terminal-based program
- Beginner-friendly Python code
